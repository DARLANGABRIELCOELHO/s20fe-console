# Referências de case mod

Links e elementos para orientar a identidade do case. Servem para discutir forma, acabamento e
soluções de montagem; a geometria do S20 FE continua sendo própria do projeto.

## Referências identificadas

- [NexDroid — Samsung DEX Case](https://cults3d.com/en/3d-model/various/samsung-dex-case): corpo
  compacto de 180 × 180 × 60 mm, com recorte para tampa transparente de acrílico. Inspiração para
  um dock de mesa e um painel removível para inspecionar o interior.
- [Duo3D — DEX Mobile Case](https://cults3d.com/en/3d-model/gadget/gabinete-celular-dex): projeto
  descrito com suporte para duas ventoinhas de 120 mm. Inspiração para deixar claro como o ar
  atravessa o aparelho; essa escala de ventoinhas não cabe no nosso envelope.
- [Duo3D — DEXMOD ONE](https://3dgo.app/models/cults3d/dexmod-one-samsung-dex-enclosure): case
  DeX de 200 × 120 × 90 mm, com suporte para ventoinha de 40 mm e linguagem minimalista. Inspiração
  para proporções de aparelho de mesa compacto.
- [Christian Selig — frente Mac Pro/XDR para SAMA IM01](https://makerworld.com/pt/models/1556271-mac-pro-xdr-inspired-sama-im01-pc-case-front):
  painel frontal com padrão de perfurações esféricas e acabamento pintado para parecer metálico.
  Inspiração para uma grelha de ventilação com identidade própria.
- [BlackHeart Factory — THINK NAS](https://makerworld.com/en/models/1368836-think-nas-lenovo-think-style-nas-case):
  gabinete com referências visuais da linha Lenovo Think e arquivo de engenharia editável.
  Inspiração para detalhes industriais, painel de I/O e peças que podem ser ajustadas ao hardware.
- [ShaunChrisPc — Open Frame ITX Stand](https://3dgo.app/models/makerworld/2577902): estrutura aberta
  que deixa os componentes visíveis e destacados do suporte. Inspiração para apoios acessíveis e
  montagem aparente, se o case seguir uma direção mais aberta.
- [HoaiNamQN — modelos de ventilação](https://cults3d.com/pt/usuarios/hoainamqn/downloads): catálogo
  inclui dutos e grelhas para ventoinhas. Inspiração para guiar o ar ao redor do dissipador.
- [Antricos — Raspberry Pi 4040 stand](https://cults3d.com/en/3d-model/tool/raspberry-pi-4040-stand):
  suporte preso a perfil 4040 com porcas T e parafusos M3. Referência para fixações ajustáveis; não
  define o estilo externo do case.

## Direção visual em aberto

As referências cobrem duas formas diferentes de apresentar o hardware: um aparelho DeX compacto e
fechado, com painel transparente opcional, ou uma estrutura aberta que destaca placa, dissipador e
ventoinha. Um ponto comum que funciona nos dois caminhos é fazer a grelha de ventilação virar um
detalhe visual intencional, mantendo as peças acessíveis para manutenção.
